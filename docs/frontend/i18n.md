# Internationalization (i18n) Documentation

The ScaleERP application supports multiple languages using `i18next` and `react-i18next`.

## Overview

| Aspect | Details |
|--------|---------|
| **Library** | i18next 25.6.1 |
| **React Integration** | react-i18next 16.2.4 |
| **Language Detection** | i18next-browser-languagedetector 8.2.0 |
| **Supported Languages** | English (en), Marathi (mr) |
| **Default Language** | English |
| **Location** | `src/i18n/` |

## Configuration

### Main Configuration (`src/i18n/index.ts`)

```typescript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';

import enTranslation from './locales/en/translation.json';
import mrTranslation from './locales/mr/translation.json';

const resources = {
  en: {
    translation: enTranslation,
  },
  mr: {
    translation: mrTranslation,
  },
};

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources,
    fallbackLng: 'en',
    debug: false,

    interpolation: {
      escapeValue: false, // React already escapes values
    },

    detection: {
      order: ['localStorage', 'navigator', 'htmlTag'],
      lookupLocalStorage: 'i18nextLng',
      caches: ['localStorage'],
    },
  });

export default i18n;
```

## Usage in Components

### Basic Usage with `useTranslation`

```typescript
import { useTranslation } from 'react-i18next';

const MyComponent = () => {
  const { t } = useTranslation();
  
  return (
    <div>
      <h1>{t('products.title')}</h1>
      <p>{t('products.description')}</p>
      <Button>{t('common.add')}</Button>
    </div>
  );
};
```

### With Interpolation

```typescript
const MyComponent = () => {
  const { t } = useTranslation();
  
  return (
    <div>
      <p>{t('products.deleteMessage', { productName: product.name })}</p>
    </div>
  );
};
```

### With Pluralization

```typescript
const MyComponent = () => {
  const { t } = useTranslation();
  
  return (
    <div>
      <p>{t('products.count', { count: products.length })}</p>
    </div>
  );
};
```

## Language Switcher Component

```typescript
import { useTranslation } from 'react-i18next';
import { Dropdown } from 'react-bootstrap';

const LanguageSwitcher: React.FC = () => {
  const { i18n } = useTranslation();
  
  const languages = [
    { code: 'en', name: 'English', flag: '🇬🇧' },
    { code: 'mr', name: 'मराठी', flag: '🇮🇳' }
  ];
  
  const changeLanguage = (code: string) => {
    i18n.changeLanguage(code);
    localStorage.setItem('i18nextLng', code);
  };
  
  const currentLanguage = languages.find(l => l.code === i18n.language);
  
  return (
    <Dropdown>
      <Dropdown.Toggle variant="outline-secondary">
        {currentLanguage?.flag} {currentLanguage?.name}
      </Dropdown.Toggle>
      <Dropdown.Menu>
        {languages.map(lang => (
          <Dropdown.Item 
            key={lang.code} 
            onClick={() => changeLanguage(lang.code)}
          >
            {lang.flag} {lang.name}
          </Dropdown.Item>
        ))}
      </Dropdown.Menu>
    </Dropdown>
  );
};
```

## Language Detection

The language is automatically detected in this order:

1. **localStorage** — Previously selected language
2. **Navigator** — Browser language
3. **HTML** — `<html lang="...">` attribute

### Persistent Storage

User's language preference is stored in localStorage:

```typescript
// When user changes language
localStorage.setItem('i18nextLng', 'mr');

// On app load, i18next reads from localStorage
// and uses that language
```

## Translation Key Structure

### Naming Convention

```
{section}.{subsection}.{key}
```

Examples:
- `common.search`
- `products.title`
- `transactions.addTransaction`
- `settings.businessSettings`

### Sections

| Section | Description |
|---------|-------------|
| `common` | Shared UI elements |
| `sidebar` | Navigation menu |
| `products` | Product management |
| `brokers` | Broker management |
| `customers` | Customer management |
| `transactions` | Transaction management |
| `leisures` | Payment management |
| `settings` | Application settings |
| `whatsapp` | WhatsApp integration |
| `database` | Database tools |

## Adding a New Language

### 1. Create Translation File

```bash
# Create new language directory
mkdir src/i18n/locales/{language_code}

# Create translation file
touch src/i18n/locales/{language_code}/translation.json
```

### 2. Add to Configuration

```typescript
// src/i18n/index.ts
import newTranslation from './locales/{language_code}/translation.json';

const resources = {
  en: { translation: enTranslation },
  mr: { translation: mrTranslation },
  {language_code}: { translation: newTranslation },  // Add here
};
```

### 3. Update Language Switcher

```typescript
const languages = [
  { code: 'en', name: 'English', flag: '🇬🇧' },
  { code: 'mr', name: 'मराठी', flag: '🇮🇳' },
  { code: '{language_code}', name: 'Language Name', flag: '🏳️' },  // Add here
];
```

## Best Practices

### 1. Always Use Translation Keys

```typescript
// ❌ Bad
<Button>Add Product</Button>

// ✅ Good
<Button>{t('products.addProduct')}</Button>
```

### 2. Use Interpolation for Dynamic Values

```typescript
// ❌ Bad
<p>Are you sure you want to delete {product.name}?</p>

// ✅ Good
<p>{t('products.deleteMessage', { productName: product.name })}</p>
```

### 3. Keep Keys Organized

Follow the section.key naming convention consistently.

### 4. Test All Languages

Ensure UI works correctly with all supported languages, including:
- Text length differences
- Right-to-left languages (if added)
- Special characters

## Troubleshooting

### Missing Translation

If a translation key is missing:
1. Check the key exists in the translation file
2. Verify the key path is correct
3. Check for typos in the key name

### Language Not Switching

If language doesn't change:
1. Check localStorage has the correct value
2. Verify i18n.changeLanguage() is called
3. Check the translation file is properly imported

### Interpolation Not Working

If interpolation doesn't work:
1. Check the variable name matches in the key and usage
2. Verify the object is passed correctly to t()
3. Check for special characters in the value
