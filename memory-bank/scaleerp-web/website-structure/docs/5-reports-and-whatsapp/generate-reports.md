# Generating Reports and Auditing Accounts

The **Reports** dashboard is where you audit your business health, check stock movements, and verify outstanding account books across customers and suppliers.

To open this page, click **Reports** in the left sidebar.

---

## 1. Finding a Report
The main reports screen categorizes documents into tabs:

> 📸 **Screenshot Placement:** *[The Reports hub showing tabs (All, Inventory, Transactions, Accounting, Master Data) and the report search box]*

* **All Reports:** Lists all reports in a grid.
* **Inventory Tab:** Focuses on stock levels and movements.
* **Transactions Tab:** Tracks purchase history and customer sales.
* **Accounting Tab:** Houses statement books like Day Book and Ledgers.
* **Master Data Tab:** Comprehensive directory sheets with contact information and balances.

You can also use the **Search Reports** search bar to quickly filter reports by typing keywords like *“sales”*, *“ledger”*, or *“stock”*.

---

## 2. Report Options & Filters
When you click any report card, a **Configure Report** window will pop up. Depending on the report type, you must select options before generating:

> 📸 **Screenshot Placement:** *[The Configure Report modal showing Date From/To pickers and the Broker/Customer optional dropdown selectors]*

* **Date From & Date To:** Select the date range to analyze (e.g., last week, this month).
* **Optional Entity Selector:** 
  * If running a *Broker Transactions* report, select a specific broker or leave as "All Brokers".
  * If running a *Customer Sales* report, select a specific customer or leave as "All Customers".
  * If running a *Stock Movement History* report, select a specific product category or leave as "All Products".

Click the blue **Generate Report** button to compile the data.

---

## 3. Supported Report Types
ScaleERP supports nine key reports:

| Report Name | What it Tracks |
| :--- | :--- |
| **Inventory Status** | Current warehouse stock quantities and total monetary value. |
| **Stock Movement History** | Log of all manual stock adjustments and automated sales/purchases. |
| **Broker Transactions** | List of all bulk wholesale purchases logged from brokers. |
| **Broker Ledger** | Statement sheet combining purchases and payments for a broker. |
| **Broker Master List** | Contacts directory showing who you owe money to. |
| **Customer Master List** | Contacts directory showing who owes you money. |
| **Customer Sales Report** | Detailed history of retail bills and invoices. |
| **Day Book** | Chronological log of all transactions (sales, purchases, payments) recorded today. |
| **Outstanding Payments** | Summary of all pending receivables vs. payables in one sheet. |

---

## 4. Exporting, Printing, & Saving
Once a report is compiled, it opens in a table viewer with utility buttons at the top right:

> 📸 **Screenshot Placement:** *[Report viewer showing generated data tables with Excel, PDF, and Print buttons active]*

* **Export Excel:** Downloads a clean spreadsheet (.xlsx) of the report data, ready to open in Microsoft Excel or Google Sheets.
* **Export PDF:** Creates a printable document file and saves it on your computer.
* **Print Report:** Opens the system print window to print a physical paper audit.
* **Change Options:** Click this button at the top header to return to filters and change dates/brokers without starting over.
