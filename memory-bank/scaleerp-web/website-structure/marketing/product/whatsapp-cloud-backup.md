## 2. Core Capabilities

### Automated Payment Reminders
Select multiple high-balance parties and send polite, formatted payment reminders directly to their WhatsApp with a single click.

### Direct WhatsApp Invoicing
Send beautifully formatted digital invoices directly to a customer’s WhatsApp right from the checkout counter. Go paperless.

### Encrypted Cloud Backups
ScaleERP runs 100% offline. But at the end of the day, a single click encrypts your entire local SQLite database and pushes a secure backup to the cloud for disaster recovery.
